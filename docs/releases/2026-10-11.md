- **Workbox Mode**: `generateSW`
- **Precached Assets**: Static assets only (`.js`, `.css`, `.html`, `.ico`, `.png`, `.svg`, `.webp`, `.woff`, `.woff2`).
- **Supabase Network Isolation**: Strict `NetworkOnly` runtime caching route for `^https://.*\.supabase\.co/.*`. No caching of `/rest/`, `/auth/`, `/functions/`, `/storage/`.
- **Navigation Fallback**: `/index.html` with denylist `/^\/(rest|auth|functions|storage)\//`.
- **Offline / Sync**: No background sync, no offline user data caching.

### F. Update Prompt & Offline Banner
- **Update Prompt**: `PwaBanners` component mounted in `App.tsx`. When a new service worker is waiting, displays a non-blocking floating banner: `"A new version is available."` with a `"Refresh"` button using UI kit `Button`. Never auto-reloads.
- **Offline Banner**: When `navigator.onLine === false`, displays a slim banner at the top: `"You're offline. MissionOS needs a connection."`

### G. Apache / LiteSpeed Configuration (`public/.htaccess`)

- Added `Header set Cache-Control "no-cache"` for `index.html`, `sw.js`, `registerSW.js`, `manifest.webmanifest`.
- Protected `sw.js`, `registerSW.js`, `manifest.webmanifest`, and `/icons/` from SPA URL rewrites.
